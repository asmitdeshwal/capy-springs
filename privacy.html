Capy Springs – Privacy Policy

Last updated: 2 October 2026 · Applies to the web, Android and iOS versions of Capy Springs

The short version: Capy Springs does not collect, store, share or sell any personal information. There are no accounts, no advertising, no analytics and no tracking of any kind.

What the game stores

Your game progress (lanterns lit, upgrades, koban, settings, daily goals and stamps) is saved only on your own device, in the app's local storage. It is never sent anywhere. Deleting the app, or choosing Reset save in the game's settings, removes it.

What the game does not do

  • It does not ask you to create an account or sign in.
  • It does not collect your name, email address, location, contacts, photos or any other personal data.
  • It does not show advertising and contains no in-app purchases.
  • It does not use analytics, crash reporting or tracking libraries.
  • It does not use cookies. The web version registers a service worker purely so the game can load offline.
  • It does not request any device permissions.

Network use

The app store versions run fully offline. The web version at asmitdeshwal.github.io/capy-springs downloads the game's own files from GitHub Pages when it is first opened or updated; GitHub may record standard server logs (such as your IP address) for that request, as any website host does. See GitHub's privacy statement.

Children

Capy Springs is suitable for all ages. Because it collects no personal information from anyone, it collects none from children either.

Changes

If this policy ever changes, the new version will be published at this address with a new "last updated" date.

Contact

Questions about this policy or the game: open an issue at github.com/asmitdeshwal/capy-springs/issues.
